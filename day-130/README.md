## What Is Backtracking?

Backtracking is an algorithmic technique used to explore possible solutions to a problem.

It involves making a choice, exploring the result of that choice, and going back when we need to try a different possibility.

The general process is:

1. **Choose:** Make a possible decision.
2. **Explore:** Continue solving the problem using that decision.
3. **Backtrack:** Undo the previous decision.
4. **Try another choice:** Explore another possibility.

This process continues until a valid solution is found or all possible choices have been explored.

## Key Idea

The important thing about backtracking is that we don't just move forward. We also undo previous choices when necessary so that we can explore other paths.

It is commonly used in problems involving combinations, permutations, subsets, and exploring possible arrangements.
