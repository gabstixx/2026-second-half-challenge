## Reading: Structural Patterns

Structural patterns deal with how classes and objects are composed into larger structures.

- **Adapter:** makes incompatible interfaces work together
- **Decorator:** adds behaviour to an object without changing its class
- **Facade:** one simple interface over a complicated subsystem
- **Proxy:** a stand-in object that controls access to another
- **Composite:** treats single objects and groups of objects uniformly

### Creational vs Structural

- Creational: how objects are created
- Structural: how objects are connected
