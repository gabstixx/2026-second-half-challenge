## What I'm Learning

Backtracking involves exploring different possibilities by:

1. Making a choice.
2. Exploring the result of that choice.
3. Undoing the choice when necessary.
4. Trying another possibility.

The important part is understanding when to make a choice, when to go deeper, and when to backtrack.
