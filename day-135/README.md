## What Is Dynamic Programming?

Dynamic Programming is a problem-solving technique where we break a problem into smaller subproblems, solve them, and store their results so we can reuse them instead of solving the same subproblems repeatedly.

It is especially useful when a problem has:

- **Overlapping subproblems:** The same smaller problems are solved multiple times.
- **Optimal substructure:** The solution to a larger problem can be built from solutions to smaller subproblems.

## Two Main Approaches

**1. Memoization (Top-Down)**

Start with the original problem and recursively break it into smaller subproblems. Store calculated results so they can be reused.

**2. Tabulation (Bottom-Up)**

Start by solving the smallest subproblems and store their results in a table or array. Use those results to build towards the final answer.

## Key Takeaway

The main idea behind DP is avoiding unnecessary repeated calculations by remembering results from previous computations.
