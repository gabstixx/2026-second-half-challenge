# Day 136/184 — Introduction to Backend Development

**Training:** HatchDev — NitHub, UNILAG

## Today's Focus

Today, we started our introduction to Backend Development in the HatchDev training.

We had an introduction to backend development, with some discussion around security and databases.

## My Biggest Takeaway

One statement from my tutor stood out to me:

**"Backend developers should have trust issues."**

The idea behind this is that we can never be certain what kind of input or request is coming into our application.

Users might submit unexpected data, send invalid requests, or even deliberately try to exploit weaknesses in the system.

As backend developers, we shouldn't assume that incoming data is safe. We need to validate inputs, handle requests properly, and put security measures in place.

## A Little on Databases

We also touched on databases and their role in backend development.

Databases store important application data, so protecting them and ensuring that data is handled properly is another important responsibility.

## Key Lesson

Today's lesson reminded me that backend development goes beyond making an application work. It also involves making sure the application can handle unexpected inputs and requests safely.

Never blindly trust incoming data.
