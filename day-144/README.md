# Day 144/184 — Introduction to Node.js and Express

**Training:** HatchDev — NitHub, UNILAG

## Today's Focus

After completing the database section of our training, we started learning Node.js and Express today.

We covered the basics of setting up a backend project and understanding how requests are handled by a server.

## What We Covered

Some of the topics and practical activities included:

- Setting up a backend project.
- Necessary terminal commands and package installation.
- Working with Node.js and Express.
- Understanding endpoints and routing.
- Handling query parameters.
- Setting up the basic structure of a backend application.

## My Observation

One thing that stood out was the difference between setting up a backend with Express and working with PHP and Laravel.

With Laravel, a lot of the project structure, configuration and essential files are already provided through its framework conventions and commands.

With Node.js and Express, we had to handle more of the initial setup ourselves, install the necessary packages and put the project structure together.

It gave me a different perspective on how backend frameworks and libraries approach application development.

## Key Takeaway

Today's session helped me understand more of the setup process behind an Express application and how routing and endpoints fit into backend development.
