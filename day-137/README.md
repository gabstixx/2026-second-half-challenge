# Day 137/184 — Introduction to PostgreSQL

**Training:** HatchDev — NitHub, UNILAG

## Today's Focus

Today, we had an introduction to PostgreSQL as part of our backend development training.

Having previously worked with PHP, Laravel and MySQL, I already had some experience working with relational databases. This session was an opportunity to get familiar with PostgreSQL and its tools.

## What I Worked On

We used pgAdmin 4 to interact with PostgreSQL and started practising basic SQL operations.

Some of the things covered included:

- Creating tables.
- Defining columns and data types.
- Setting primary keys.
- Inserting records into tables.

I also got to practise writing SQL queries directly in pgAdmin.

## Key Takeaway

Although PostgreSQL and MySQL are different database systems, the relational database concepts I've worked with before still provide a foundation for learning PostgreSQL.

This is another step in expanding my backend development skills and becoming more comfortable working with different database technologies.
